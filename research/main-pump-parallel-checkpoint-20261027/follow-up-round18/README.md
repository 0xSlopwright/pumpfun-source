# Main Pump follow-up research

This snapshot preserves the creation, V2 transfer, V3 net-budget and V3 sell-supply lanes, including negative and unfinished controls. It is evidence, not the maintained source selection. Round18 is selected separately; Round19 was still undergoing combined validation at capture time. Compiler/dependency caches, symlinks and private-key files are excluded.

`MANIFEST.json` records each captured file and compressed part. Concatenate the numbered parts to inspect the tar archive; extraction does not select or execute a variant.

The intermediate Round19 full run was subsequently stopped before completion to combine further verified fixes. Its partial results are not a completed checkpoint; see `round19-superseded.json`.
