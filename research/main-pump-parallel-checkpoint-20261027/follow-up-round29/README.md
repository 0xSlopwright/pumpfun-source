# Main Pump follow-up research

This snapshot preserves the optional main-Pump linker recipe, its fresh-build proofs and negative controls, expanded error-order coverage, and compiler-provenance evidence. It is evidence, not the maintained source selection. The final Round29 selection and verification are recorded separately. Compiler/dependency caches, symlinks and private-key files are excluded.

`MANIFEST.json` records each captured file and compressed part. Concatenate the numbered parts to inspect the tar archive; extraction does not select or execute a variant.
