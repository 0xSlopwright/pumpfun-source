# Original portfolio visibility reads

This reconstructs the read boundary in factories **261756** and **947305**:
the dust-floor getter, spam-mint getter, query keys, five/eight-slot memoized query
options, and local array-cache helpers. Both queries have actual captured
consumers. The previously inventoried code had no maintained callable module.
The private **670607** dust-floor POST/setter remains excluded from implementation.

## Physical source

`contract.json` is regenerated by static AST inspection of authenticated original
captures. It records source URL, capture/factory hashes, UTF-16/UTF-8 ranges and
the actual used call expressions. No captured factory or library is executed.

- **261756**, SHA `4ac26c6e…`, UTF-16 `[6059,7469)` and **947305**, SHA
  `14c50390…`, `[10036,11079)` share `4fd6e792e7a336d9.js`.
- Actual **400466** calls are `(0,ek.$)(u)` and `(0,eE.y)(d)` in
  `13c13db9eb86191b.js`. The **150430** portfolio-table factory also calls
  `(0,H.$)(v)` in `1861f564fee26935.js`. These are bounded call witnesses, not
  a claim that either whole consumer or an individual token page is reconstructed.
- Both inventoried **582453** factory variants remain explicit. Their complete
  bodies differ, while the used normalization arrow is literally identical:
  SHA `4e825181…`. The module lowercases a mint only when it starts with the
  lowercase prefix `0x`; it does not lowercase Solana or uppercase `0X` strings.
  This closes the used function without selecting an arbitrary global variant.
- **759257.j** → **30181.K**, **503630.R** and **898661** establish the website
  request origin/options/encoding. The origin is
  `https://frontend-api-v3.pump.fun`, not the public developer API host. Neither
  current provider availability nor authenticated server ownership is established.

Whole selected factory hashes are pinned. A changed capture or a resealed guard
change requires renewed review; regeneration does not silently approve it.

## Request, cache and response behavior

The dust query key is `['userPortfolioDustFloor', address]`, staleTime 60 seconds.
Its GET `/user-portfolio/dust-floor` uses `credentials:'include'`, the query
function's AbortSignal, `throwHttpErrors:false` and a non-ok response hook.
**No address, query or body is sent.** A cache address is not an authenticated
principal; the server's actual session/provider behavior remains outside this unit.

The getter returns `dustFloorUsd` only when it is a number greater than zero,
otherwise null. It does not coerce strings, check finiteness, or impose the
separate dialog's maximum. In particular positive infinity is retained. The
loopback test uses the valid JSON numeric spelling `1e400` to exercise this
original client quirk without executing captured code or changing its policy.

The spam key is `['userPortfolioSpamMints', address]`, staleTime 30 seconds.
GET `/user-portfolio/{userId}` uses `address ?? ''`, query
`filter:'open', spamOnly:true, sortBy:'POSITION_SIZE', page:0, pageSize:200`,
include credentials, query AbortSignal and its non-ok hook. It maps `coinMint`
through the observed normalizer, deduplicates, and applies native lexicographic
sort. Its query select function makes a new Set. It does not paginate beyond
that captured request, substitute empty malformed responses, or add schema checks.

Both hooks compute `!!address && enabled` with **no default** for enabled. An
empty address gives false; a truthy address with enabled undefined retains
undefined for the real query runtime to interpret. Five/eight-slot memoization
retains the captured key/callback/options identities. Old callbacks keep their
original captured address after a later hook call. The ports do not establish
React mount, scheduler, cancellation, cache-placeholder or network lifecycle
parity merely from these finite option/callback tests.

Non-ok hooks throw the captured status-only messages. Transport/JSON/type errors
propagate. The cache helpers are pure local transforms: membership, append-if-
absent and remove-if-present. Unchanged arrays retain identity. They do not send
POSTs, update an owner preference or promise persistence.

## Use

```js
import { createPortfolioReadPolicies } from
  '../../packages/frontend/src/original-contracts/portfolio-read-policies/client.mjs';

const policies = createPortfolioReadPolicies({
  createClient: explicitContractClientConstructor,
  memo: explicitReactCompilerMemoRuntime,
  useQuery: explicitQueryHook,
});
// Invoke hooks only within the actual supplied React/query runtime.
const query = policies.useDustFloor({ address, enabled });
```

The injected memo runtime must supply separate correctly initialized caches for
each actual hook instance, as the captured 445242.c dependency does. The tests'
inert cache/query recorder is not installed as an application runtime. For a
non-hook read, `policies.readDustFloor({signal})` only needs the client constructor.

`local-http.mjs` provides an explicitly selected single-attempt HTTP(S) client
for the two GETs. Its native request, response-hook and JSON handling let the
callbacks run over real local HTTP. It chooses no default destination and adds
no auth header/cookie jar. URL restrictions and the two-operation allowlist are
local adapter policy. It does not emulate original Ky retries/timeouts, normalized
hook options, contract-error wrapping, browser cookies or authenticated ownership.
Original memo/query providers are neither installed nor guessed.

## Verify and limits

From the repository root:

```sh
node app/scripts/original-portfolio-read-policies.mjs --check
node --test app/tests/original_source.test.mjs app/tests/original_portfolio_read_policies.test.mjs
```

The 12 new tests cover actual source consumers/variant closure, raw enabled and
memo identities, retained-address callbacks, request fields, signal forwarding,
numeric/default quirks, normalization/sort/Set behavior, local array identity,
401/403 hooks, cancellation, malformed responses and source resealing. Six real
loopback HTTP responses are retained with explicitly synthetic service payloads.
The only omitted wire field is the ephemeral loopback origin. Eleven shared
source-verifier tests also run. The immutable base lacks both maintained module
paths; no fabricated baseline HTTP response is used as a before proof.

No production request, backend route, owner preference write, wallet session,
signing, holdings source, pricing/PnL/indexer, React provider, UI/SearchDialog
integration, token page or visual parity is qualified. Original library runtime,
server semantics and auth remain unknown. SDK/capture bytes and feature/native
qualification counts are unchanged. Frozen hashes, logs and wire receipts are
under `validation/`; broad app/Next/browser runs remain shared validation.
