## Acceptance and limitations

- Desktop keeps identity, full wallet address, counts, disabled actions, and the
  authored post in a bounded reading column.
- Mobile wraps the full address, stacks controls, retains 44-pixel copy target,
  and avoids document-level horizontal overflow.
- No captured reference profile exists at an equivalent identity and viewport.
  The screenshots qualify local responsiveness only, not original visual parity.
