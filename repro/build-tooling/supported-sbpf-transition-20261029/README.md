# Installed SBPF helper transition

These exact helper bytes and diffs bridge the frozen supported-SBPF tooling
receipts to the reviewed installed scripts. The historical adapter is rebuilt as
data from its archived adapter plus archived hardening block; the historical
source inventory is the proposal's archived utility. Both must still match the
original installed-file pins before entering the historical verification view.

The installed adapter includes PR #666's foreign-path rejection and an explicit
leading-separator check for modern ntpath semantics. The current source inventory
uses POSIX snapshot keys. The original policy pins are retained: this transition
does not admit a new real v1.53/v1.54 build or fabricate compiler evidence.

The mutable history bridge runs the unchanged historical verifier on reconstructed
historical bytes and checks the actual selected Mayhem canonical checkpoint through
its owning verifier. The old initializer candidate remains an authenticated
historical receipt and is not substituted into the current selection.

Validation uses synthetic planner/policy fixtures and saved checkpoint evidence.
No Cargo, rustc, VM or cold build is invoked. All frozen packets remain unchanged.
