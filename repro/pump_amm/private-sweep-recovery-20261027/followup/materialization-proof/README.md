# Smaller future AMM checkpoints

The current H11 result tree contains 4,210,952,440 logical bytes across 19,466 files. Twenty-one historical top-level lineage directories account for 2,778,726,394 bytes and 12,993 files but are not read by either current saved-proof component. Omitting those copies removes 66.0% of the result payload before outer-manifest changes. Their complete bytes remain in the immutable H11 checkpoint; the proposed metadata records its manifest hash and repository-relative archive paths.

Both unchanged `verify_new_proofs.py` and `verify_recovery.py` passed against an isolated APFS COW copy with those directories removed. Their complete retained result files were independently checked against the original outer manifest: 6,472 files and 1,428,638,247 payload bytes. The outer manifest was deliberately left unchanged in the experiment; a future freeze must regenerate it and update the ordinary checkpoint seal.

The Python audit hook covered the parent verifier and nested `range-joint` verifier. It rejects any access to the original H11 checkpoint and observed exactly these nine retained lineage directories: `buy-event`, `cpi-branches`, `fourth`, `incentive-order`, `independent-range`, `protocol-recipient`, `protocol-sweep`, `range-joint`, and `route-guard-component`. Both native-fee and legacy-exact packets, static proofs, fresh receipts, all loose lineage files, and every nested file in each retained sealed packet remain intact. No compiler or VM ran. Static source-patch verification used fresh temporary copies. Two negative controls separately removed `protocol-recipient` and `route-guard-component`; the unchanged recovery and expanded verifiers rejected the exact missing packet, and both private directories were restored.

`materialization.patch` changes only the coordinator's `freeze.py` and `finalize-proofs.py`, plus a small shared `materialize_lineage.py` helper. Finalization copies six inherited required directories, writes archive-omission metadata, and adds the three newly sealed current-candidate packets. Freeze applies the same whole-directory filter as a guard. The helper accepts `retained_names=` in both functions, so H12 can pass renamed current-joint or independent packet names. The same set must be used by finalization, omission metadata, and freeze. The allowlist must track future verifier dependency changes; any missing required packet fails ordinary saved verification before publication. No contract source or existing checkpoint was modified.

The saved components took 12.84 and 48.99 seconds in this run. Those are observations, not a before/after speed benchmark. Fewer logical bytes and directory entries should reduce materialization and outer-manifest work, but Git object reuse, compression, physical disk savings, and end-to-end publication speed were not measured.

The first comparison wrapper stopped after the expanded verifier had passed because the root summary deliberately overwrites `buyback_cases` with a different suite's count (72 versus this component's 24). The wrapper was corrected to compare only fields not overridden by the root's literal summary entries. The second run passed both unchanged components. Both logs are retained; this was a report-composition error, not a contract test failure.
